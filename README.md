PirateCast

PirateCast — интеграция для Home Assistant, которая рассчитывает изменение атмосферного давления по истории исходного сенсора.

Возможности

- Изменение давления за последний час.
- Изменение давления за последние три часа.
- Перевод поддерживаемых единиц давления в мм рт. ст.
- Использование сенсоров в автоматизациях, стандартных карточках Home Assistant и сторонних Lovelace-карточках.

Интеграция не устанавливает и не регистрирует пользовательские карточки. Для визуальной шкалы предназначен отдельный репозиторий "PirateCast-Card" (https://github.com/devil2012devil/PirateCast-Card).

Требования

- Home Assistant.
- Включённая запись истории сенсора в Recorder.
- Сенсор атмосферного давления с числовыми значениями и единицей измерения.

Установка через HACS

1. Откройте HACS.
2. Перейдите в раздел интеграций.
3. Откройте меню пользовательских репозиториев.
4. Добавьте "https://github.com/devil2012devil/PirateCast".
5. Выберите категорию Integration.
6. Установите PirateCast.
7. Перезапустите Home Assistant.
8. Откройте Настройки → Устройства и службы → Добавить интеграцию.
9. Найдите PirateCast.
10. Выберите исходный сенсор атмосферного давления.

Сенсоры

Интеграция создаёт два сенсора:

- "sensor.piratecast_pressure_change_1h"
- "sensor.piratecast_pressure_change_3h"

Если в системе уже существует сущность с таким ID, Home Assistant может назначить другой ID. В этом случае проверьте фактический ID в разделе Инструменты разработчика → Состояния.

Результат выражается в мм рт. ст.:

- отрицательное значение — давление снизилось;
- положительное значение — давление повысилось;
- значение около нуля — существенного изменения за рассматриваемый интервал не обнаружено.

Единицы измерения

Поддерживаются следующие единицы исходного сенсора:

- "mmHg"
- "hPa"
- "mbar"
- "Pa"
- "kPa"
- "inHg"

Если единица неизвестна или отсутствует, сенсор не выдаёт расчётное значение.

Как рассчитывается изменение

Интеграция читает историю выбранного сенсора за соответствующий временной интервал и вычисляет разницу между первым и последним подходящими числовыми значениями.

Для корректного результата Home Assistant должен сохранять историю исходного сенсора. Если данных недостаточно, сенсор временно не будет иметь доступного числового значения.

Важно: результат зависит от доступных записей истории. Если в начале интервала нет подходящей записи, расчёт может охватывать не весь заданный промежуток. Это изменение давления за выбранный интервал, а не прогноз погоды и не скорость изменения в данный момент.

Отображение на карточке

Для визуализации можно установить отдельную карточку:

"PirateCast-Card" (https://github.com/devil2012devil/PirateCast-Card)

Она отображает шкалу изменения давления, маркер текущего значения и стрелку направления изменения.

Устранение неполадок

Сенсоры отсутствуют

- Убедитесь, что интеграция добавлена в Home Assistant.
- Проверьте журнал Home Assistant на наличие ошибок PirateCast.
- Убедитесь, что исходный сенсор существует и имеет числовое состояние.

Значение недоступно

- Проверьте, включена ли запись исходного сенсора в Recorder.
- Убедитесь, что в истории достаточно числовых записей.
- Проверьте единицу измерения исходного сенсора.

ID сенсора отличается от указанного в документации

Откройте Инструменты разработчика → Состояния и найдите сущности PirateCast. Используйте фактический ID в конфигурации карточки.
